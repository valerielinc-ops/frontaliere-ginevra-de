System Engineer – Automatisierung (Windows/VMware)

Wir suchen einen Windows Systems Engineer mit einer starken Leidenschaft für Automatisierung und Infrastrukturoptimierung. Sie werden sich einem dynamischen Team von 15 System Engineering-Experten anschließen, die eine globale Infrastruktur von mehr als 7.000 Servern verwalten. Dies ist ein großes technisches Umfeld, in dem Expertise, Innovation und fortschrittliche Automatisierung im Mittelpunkt unserer Mission stehen. Sie werden eine Schlüsselrolle bei der Entwicklung und Standardisierung unserer IT-Landschaft spielen, mit einem starken Fokus auf PowerShell, VMware Aria / vRealize Automation und Windows-Technologien wie Windows Server und Active Directory. Sie werden in die Gestaltung, Implementierung und Wartung von Automatisierungslösungen einbezogen, die darauf abzielen, die Betriebseffizienz zu verbessern und manuelle Eingriffe zu reduzieren. Wir fördern aktiv Innovationen und den Vorschlag neuer Ideen zur Verbesserung unserer Plattformen. Derzeit treiben wir mehrere strategische Initiativen voran, darunter das Upgrade auf VMware Cloud Foundation 9 (VCF 9) zur Modernisierung unseres Virtualisierungsstacks sowie ein Beobachtungsprojekt der nächsten Generation auf Basis von Elastic-Lösungen.

IHRE ROLLE

  • Entwerfen, Entwickeln und Pflegen von erweiterten PowerShell-Scripts zur Automatisierung von Systemadministrationsaufgaben.
  • Bereitstellen, Pflegen und Optimieren von VMware Aria / vRealize Automation Workflows und Blueprints.
  • Beteiligen Sie sich an der Verwaltung und Entwicklung von Windows-Plattformen, einschließlich Windows Server, Active Directory / ADFS / GPO, SCCM (Microsoft Endpoint Configuration Manager).
  • Beitrag zur Einführung von Infrastructure as Code (IaC) -Praktiken.
  • Gewährleistung von Leistung, Sicherheit und Zuverlässigkeit in der gesamten virtuellen und physischen Infrastruktur.
  • Arbeiten Sie eng mit Netzwerk-, Sicherheits- und Entwicklungsteams zusammen, um Automatisierungslösungen im gesamten Unternehmen zu integrieren.
  • Unterstützung von Industrialisierungsbemühungen, Migrationen und kontinuierlichen Verbesserungsprojekten.

IHR PROFIL

  • Hervorragender Befehl über Windows Server Administration.
  • Hervorragender Befehl von PowerShell (Scripting, Module, APIs, End-to-End-Automatisierung).
  • Gute Beherrschung von VMware Aria / vRealize Automation (vRA, vRO, Blueprints, Workflows). Die Kenntnis anderer Aria-Suite-Komponenten gilt als Vermögenswert.
  • Kenntnisse über Virtualisierungstechnologien (VMware vSphere).
  • Wissen über Infrastructure as Code (IaC), CI/CD für Automatisierung, REST APIs und Systemintegrationen
  • Erfahrungen mit Azure, Terraform, GIT und Ansible gelten als Asset.
  • Starke Problemlösungsmentalität und kontinuierliche Verbesserungsorientierung.
  • Fähigkeit, unabhängig in einem komplexen Umfeld zu arbeiten.
  • Starke Serviceorientierung und ausgezeichnete Kommunikationsfähigkeiten.
  • Analytischer Ansatz und strenge Dokumentationspraktiken.
