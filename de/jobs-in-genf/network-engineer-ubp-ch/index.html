Vollständige Beschreibung

Mission Als Network and Voice Engineer spielen Sie eine entscheidende Rolle bei der Verwaltung und Verbesserung unserer globalen Netzwerkinfrastruktur. Ihre Expertise ist von entscheidender Bedeutung, um eine hohe Verfügbarkeit, Leistung und Sicherheit unserer IT-Services zu gewährleisten. Teil a des Teams, werden Sie für die Netzwerkaktivitäten auf globaler Ebene für die Gruppe verantwortlich sein, Unterstützung LAN / MAN / WAN, WiFi, Security Firewall, Load Balancing, DDoS ect.. Herausforderungen Entwickeln Sie sich in einem herausfordernden, regulierten Umfeld für eine schnelle und wachsende Privatbank. Unterstützen Sie eine große Menge an Technologie in einer international verteilten Umgebung. Hauptzuständigkeiten

  • Verwalten Sie die Warteschlange für Vorfälle und stellen Sie sicher, dass diese rechtzeitig behoben werden (Überwachung, Untersuchung, Lösung, Nachverfolgung)
  • Verwalten Sie den Lebenszyklus der Netzwerkumgebung (LAN/MAN/WAN/Wifi...)
  • Verwalten Sie den Lebenszyklus der Sprachumgebung (CUCM, NICE Voice Recording-Lösungen ...)
  • Verwalten Sie den Lebenszyklus der Sicherheitsumgebung (PaloAlto/Bluecoat/F5/IronPort/SandBlast...)
  • Arbeiten Sie mit dem Team an allen Infrastrukturprojekten, bei denen Netzwerk / Sicherheit erforderlich ist
  • Arbeiten Sie mit externen Anbietern innerhalb von Incident / Project / BAU (Dienstleister, Carrier, Telco ...)
  • Bestandsaktualisierungen, Kapazitätsplanung, KPI-Tracking sicherstellen
  • Werden Sie Teil eines Netzwerkteams und Sicherheitsbetriebsteams eine große Anzahl von Umgebungen zu verwalten
  • Bereit, Aufgaben außerhalb der Bürozeiten in der Produktionsumgebung auszuführen
  • Seien Sie Teil einer On-Call-Service-Rotation eine Woche pro Monat (24/24-7j/7)
