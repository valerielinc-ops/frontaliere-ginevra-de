Vollständige Beschreibung

Missionskontext Im Rahmen der Wartung und Weiterentwicklung seiner kollaborativen Plattformen sucht unser Kunde einen Senior SharePoint Consultant / Microsoft 365. Sie werden in SharePoint On-Premises und Microsoft 365-Umgebungen intervenieren, mit einer zentralen Rolle in der Verwaltung, dem Level 3-Support, der komplexen Incident-Lösung und der fortschreitenden Transformation zu Microsoft Cloud-Lösungen.

Ihre Aufgaben

  • Verwalten und pflegen Sie SharePoint On-Premises- und SharePoint Online-Umgebungen unter Betriebsbedingungen.
  • Bereitstellung von L3-Unterstützung und Bewältigung komplexer Vorfälle.
  • Gewährleistung der Verfügbarkeit, Stabilität und Leistung von Kooperationsplattformen.
  • Verwalten Sie die wichtigsten Microsoft 365 zugehörigen Dienste.
  • Automatisieren Sie Verwaltungs- und Betriebsaufgaben mit PowerShell.
  • Beteiligen Sie sich am Identitäts- und Zugriffsmanagement mit Microsoft Entra ID, einschließlich Authentifizierung, Autorisierung, bedingter Zugriff, App-Registrierungen und Microsoft Graph API.
  • Tragen Sie zu Microsoft 365-Sicherheits-, Compliance- und Governance-Problemen bei.
  • Beteiligen Sie sich an ITSM-Prozessen: Incident, Problem and Change Management.
  • Identifizieren Sie wiederkehrende Vorfälle und implementieren Sie Korrekturmaßnahmen und Automatisierung.
  • Nehmen Sie an SharePoint On-Premises-Migrationsprojekten zu SharePoint Online teil.
  • Erstellung und Pflege der technischen Dokumentation und Sicherstellung des Wissenstransfers.
  • Arbeiten Sie mit Infrastruktur-, Sicherheits-, Trades- und Projektteams in einer Agile/Scrum-Umgebung zusammen.

  • 7 Jahre Mindesterfahrung in SharePoint- und Microsoft 365-Umgebungen.
  • Expertise in der Verwaltung und Wartung von SharePoint On-Premises.
  • Sehr gute Kontrolle über SharePoint Online und Microsoft 365.
  • Erfahrung bestätigt im technischen Support L3 .
  • Hervorragende Beherrschung von PowerShell für Verwaltung und Automatisierung.
  • Gute Kenntnisse der Microsoft Entra ID / Azure AD:
  • Authentifizierung und Autorisierung;
  • Bedingter Zugang;
  • Registrierung von Apps;
  • Microsoft Graph API.
  • Gutes Verständnis von Microsoft SQL Server, Active Directory und Netzwerkkonzepten.
  • Steuerung von Microsoft 365 Sicherheits-, Compliance- und Governance-Problemen.
  • Kenntnisse über ITSM-Prozesse, einschließlich Incident, Problem- und Change Management.
  • Erfahrung in einer Agile/Scrum-Umgebung.

Bewertete Kompetenzen
